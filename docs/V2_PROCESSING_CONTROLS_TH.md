# V2: เชื่อมสไลเดอร์กับการประมวลผลจริง

ชุดแก้ต่อจาก dev/niyomsil-design-v2 (2c39755) เฉพาะ V2 ไม่แก้ V1

- ลดนอยส์ เกลี่ยพื้นสีเรียบ ตัวอักษร/โลโก้ และ Anti-Halo Sharpen ใช้ค่าจากหน้าจอในเส้นทาง AI ทั้งภาพปกติและภาพแบ่งส่วนบนดิสก์
- ตั้งทั้งสี่ค่าเป็น 0 จะไม่เปลี่ยนพิกเซลในขั้นตอนเก็บรายละเอียดเพิ่มเติม (AI และการปรับขนาดยังทำงานตามเดิม)
- ทำขั้นตอนนี้ก่อนกู้คืนใบหน้า ไม่ข้ามข้อความทั้งภาพเพียงเพราะเปิด Recover หรือเพราะไม่มีกรอบใบหน้าที่เลือกไว้
- เว้นบริเวณใบหน้าที่เลือกและระยะเผื่อ รักษาค่า alpha ของ PNG
- จำกัดการเปลี่ยนสีไม่เกิน 15 ระดับต่อช่องสี และไม่สร้างค่าสีสูง/ต่ำกว่าบริเวณใกล้เคียง

การตรวจในสภาพแวดล้อม Linux: pytest ทั้งชุด 185 passed, 1 skipped; compileall ผ่าน
ทดสอบสไลเดอร์แต่ละตัวผ่านการส่งออกจริงโดยใช้เครื่องยนต์ขยายภาพจำลอง รวมถึงกรณีการกู้คืนใบหน้าล้มเหลวและการแบ่งส่วนบนดิสก์

ข้อจำกัด: ยังไม่ได้ทดสอบตัวติดตั้ง Windows หรือรัน Real-ESRGAN/GFPGAN บนงานลูกค้าจริงในรอบนี้ การเก็บรายละเอียดนี้ไม่ใช่ OCR หรือการสร้างเส้นเวกเตอร์ใหม่ จึงไม่รับประกันว่าจะซ่อมรูปทรงตัวอักษรที่บิดผิดจากต้นฉบับได้ทั้งหมด Local Contrast และ Saturation ยังไม่ได้เชื่อมในชุดแก้นี้ การแปลง ICC คงเป็นขั้นตอนส่งออกเดิม
