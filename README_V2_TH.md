# NiyomSilp Design v2

รุ่นทดสอบสำหรับ Windows 64 bit ของร้านนิยมศิลป์ดีไซน์

เปิดไฟล์ `NiyomSilp-Design-v2-Install.exe` เพื่อดาวน์โหลดและตรวจส่วนประกอบอัตโนมัติ แล้วทำตามหน้าจอติดตั้ง ต้องใช้อินเทอร์เน็ตระหว่างดาวน์โหลดครั้งแรก หลังติดตั้งโปรแกรมและโมเดลทำงานได้แบบ offline และไม่ต้องติดตั้ง Python

โปรแกรมติดตั้งที่ `NiyomSilpDesignV2` และใช้ทางลัดชื่อ `NiyomSilp Design v2`

- ลากภาพเข้าหน้าต่าง เลือกขนาดจริง หน่วย และ DPI หรือพิมพ์อัตราขยายปลายทาง เช่น 16x
- ล็อกสัดส่วนใช้ Fit; ปลดล็อกใช้ Stretch เต็มพื้นที่ที่ป้อน
- งานใหญ่ใช้ดิสก์และแบ่งส่วนประมวลผล ให้เตรียมพื้นที่ว่างสำหรับไฟล์ระหว่างทำงานและผลลัพธ์
- เลือก PNG/TIFF/PDF สำหรับด้านภาพที่ยาวกว่า 65,500 px; JPG มีข้อจำกัดจากรูปแบบไฟล์
- ตัวอย่างย่อบนจอไม่ลดจำนวนพิกเซลของไฟล์ส่งออก
- ใช้ AUTO ให้โปรแกรมตรวจ GPU หรือเลือก CPU/GPU ในรายการอุปกรณ์

รุ่นนี้ยังใช้ checkpoint RealESRGAN_x4plus, GFPGAN และ RetinaFace เดิมตาม notices ที่แนบมา ยังไม่ได้สลับเป็น native weights ใหม่

ก่อนเผยแพร่ ชุดติดตั้งต้องผ่านการตรวจการแพ็ก การติดตั้ง และประมวลผลจริงบน Windows CPU ใน CI การทำงาน CUDA/DirectML และคุณภาพของภาพร้านต้องทดสอบบนเครื่องใช้งานจริง

สำหรับชุดติดตั้งแบบ offline ให้ดาวน์โหลด `NiyomSilp-Design-v2-Setup.exe` และไฟล์ `.bin` ทุกไฟล์ใน release เดียวกันไว้ในโฟลเดอร์เดียว แล้วเปิดไฟล์ Setup
